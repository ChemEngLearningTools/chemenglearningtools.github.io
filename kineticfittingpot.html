KineticFittingPot

Interactive isothermal batch reactor simulation, kinetic parameter estimation from experimental data and model validation for chemical engineering teaching and independent study.

Launch KineticFittingPotBack to all tools

Explore reaction kinetics using simulation and data

KineticFittingPot connects reaction stoichiometry, rate expressions and batch reactor mole balances to measured concentration profiles. Start with a built-in example, or define a reaction network in an Excel workbook and simulate its response.

For parameter estimation, the application numerically integrates the reaction model and uses multistart nonlinear least squares to fit kinetic parameters to selected experimental datasets. Separate validation datasets can be compared with predictions without including their measurements in the fitting objective.

Useful for

  • Teaching batch reactor kinetics and numerical ODE simulation
  • Fitting reaction-rate parameters to time–concentration measurements
  • Comparing fitted trajectories with independent experimental data
  • Exploring residuals, stoichiometric constraints and model limitations
  • Studying an example of biodiesel kinetic fitting
