What is ChemEngDiagramPot?

ChemEngDiagramPot is being developed as a teaching-oriented alternative to general drawing software for common chemical-engineering diagrams.

It combines semantic engineering symbols, connection ports, orthogonal routing, editable project files and SVG export.

Current diagram families

  • Block Flow Diagrams (BFDs)
  • Control System Block Diagrams
  • Process Flow Diagrams (PFDs)
  • Piping & Instrumentation Diagrams (P&IDs)

Current capabilities

Engineering symbol libraryProcess equipment, control components, valves, flow elements, instrumentation and annotations.
Semantic connectionsPort-to-port connections, orthogonal routing, material and signal line types, arrows and labels.
Editable projectsDiagrams are saved as JSON project files so they can be reopened and modified.
Vector exportDark-app and light-document SVG export for web teaching tools, PowerPoint and Word.
ChemEngDiagramPot is not yet publicly deployed. This page documents the project while development and classroom-oriented refinement continue.
